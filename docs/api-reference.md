# API Reference — @rytass/wms-module-*

Complete export catalog for the three publishable libraries:

- `@rytass/wms-module-core` — NestJS module, TypeORM entities, services, DI tokens
- `@rytass/wms-module-graphql` — GraphQL resolvers, DTOs, DataLoader helpers
- `@rytass/wms-module-react` — React components, hooks, Apollo client, GraphQL operations

Current versions: **0.1.2** (all three packages).

This document mirrors the actual `src/index.ts` barrel exports and is generated by static analysis of the lib sources. For runtime behavior changes between versions, see each package's `CHANGELOG.md`.

> Companion document — **[Integration Guide](./integration-guide.md)** — step-by-step instructions for wiring the three packages into a new consumer project.

# @rytass/wms-module-core

## NestJS Modules

### `WmsModuleCoreModule`
- 用途: WMS 核心 NestJS 動態模組，整合 TypeORM 實體、服務與 Vault 認證；透過 `forRoot` / `forRootAsync` 初始化整個核心功能。
- 來源: `lib/core.module.ts`

**`forRoot(options, coreOptions): DynamicModule`**
```ts
static forRoot(
  options: WMSBaseModuleOptions,          // @rytass/wms-base-nestjs-module 選項（DB 連線等）
  coreOptions: WmsModuleCoreModuleOptions, // defaultLoaderSerialId / defaultLoaderTypeKey / defaultLocationKey
): DynamicModule
```

**`forRootAsync(options): DynamicModule`**
```ts
static forRootAsync(
  options: WmsModuleCoreModuleAsyncOptions, // WMSBaseModuleAsyncOptions + WmsModuleCoreModuleOptions
): DynamicModule
```

### `ModelsModule`
- 用途: 內部模組，向 TypeORM 註冊所有 WMS 實體（via DI token 形式），並透過 `ResolvedEntitiesProviders` 提供 DI。**消費端不直接 import**；它由 `WmsModuleCoreModule.forRoot` 自動引入並 re-export。
- 來源: `lib/models/models.module.ts`

# @rytass/wms-module-graphql

## NestJS Modules

### `WmsModuleGraphqlModule`
- 用途: WMS GraphQL NestJS 動態模組，整合 Apollo GraphQL、DataLoader 與所有 Resolver/Query/Mutation。是消費端 `apps/api` 唯一需要 `imports: [...]` 的 WMS 模組。
- 來源: `lib/graphql.module.ts`

**`forRootAsync(options, gqlOptions): DynamicModule`**
```ts
static forRootAsync(
  options: WmsModuleCoreModuleAsyncOptions,
  // WMSBaseModuleAsyncOptions（Vault/DB 選項）
  // + WmsModuleCoreModuleOptions:
  //     defaultLoaderSerialId: string  — 庫存作業預設載具序號
  //     defaultLoaderTypeKey: string   — 預設載具類型 key
  //     defaultLocationKey: string     — 預設儲存位置 key
  gqlOptions: GqlModuleAsyncOptions,
  // 標準 @nestjs/graphql GqlModuleAsyncOptions，
  // 例如 autoSchemaFile、context factory 等
  // 注意：此方法會自動在 context 中注入 loaders（DataLoader instances）:
  //   loaders.batchSingle — DataLoader<LoaderOptions<T>, T>
  //   loaders.batchMany   — DataLoader<LoaderOptions<T>, T[]>
  //   loaders.batchManyWithPagination — DataLoader<LoaderOptionsWithPagination<T>, { items: T[]; total: number }>
): DynamicModule
```

## DataLoader Helpers

### `LoaderService` (`@Injectable()`)
- 用途: LRU 快取 DataLoader 工廠，防止 GraphQL N+1 查詢。
- 來源: `lib/helpers/loader.service.ts`

```ts
class LoaderService {
  batchEntity<T>(): DataLoader<LoaderOptions<T>, T>
  batchEntities<T>(): DataLoader<LoaderOptions<T>, T[]>
  batchEntitiesWithPagination<T>(): DataLoader<LoaderOptionsWithPagination<T>, { items: T[]; total: number }>
}
```

### `LoaderOptions<K>` (interface)
```ts
interface LoaderOptions<K> {
  __entity: ObjectLiteral;         // TypeORM entity class
  __from: FindOptionsWhere<K>;     // 查詢條件（主鍵）
  __conditions?: (qb: SelectQueryBuilder) => SelectQueryBuilder; // 可選 query builder hook
  __seed?: string;                 // cache key 用的額外 seed
  __pagination?: { offset: number; limit: number };
}
```
來源: `lib/helpers/loader.service.ts`

### `LoaderOptionsWithPagination<K>` (interface)
- 繼承 `LoaderOptions<K>`，`__pagination` 為必填。
- 來源: `lib/helpers/loader.service.ts`

### `LoaderType<T>` (interface)
```ts
interface LoaderType<T> {
  loaders: {
    batchMany: DataLoader<LoaderOptions<T>, T[]>;
    batchSingle: DataLoader<LoaderOptions<T>, T>;
    batchManyWithPagination: DataLoader<LoaderOptionsWithPagination<T>, { items: T[]; total: number }>;
  };
}
```
- 用途: 定義 GraphQL context 中 `loaders` 欄位的型別。
- 來源: `lib/helpers/dataloader.type.ts`

### `HelperModule`
- 用途: `@Global()` NestJS 模組，提供 `LoaderService`；由 `WmsModuleGraphqlModule.forRootAsync` 自動 import。
- 來源: `lib/helpers/helper.module.ts`

### `QueryPath`
- 用途: NestJS param decorator，從 GraphQL ExecutionContext 萃取目前 resolver 路徑字串（如 `"materials/aggregatedStock"`）。
- 來源: `lib/helpers/query-path.ts`

#### `createApolloClient(): ApolloClient<NormalizedCacheObject>`
- Purpose: Factory function that creates an Apollo client with error link, auth link (extensible for Authorization headers), and HttpLink pointing at `/graphql`.
- Source: `apollo/index.ts`

```ts
export const createApolloClient: () => ApolloClient<NormalizedCacheObject>
```

As of 0.1.2, this factory takes **no parameters** and returns a fresh instance with `/graphql`
as the endpoint URI (the same as the default singleton). A URL/header override parameter is
planned for 0.2.0 (semver minor, non-breaking addition).

// Correct — named import:
import { ApolloClient, createApolloClient } from '@rytass/wms-module-react';
